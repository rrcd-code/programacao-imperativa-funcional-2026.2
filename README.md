# Programação Imperativa e Funcional (PIF) — 2026.2

Este repositório contém as soluções das listas de exercícios e projetos desenvolvidos durante a disciplina de **Programação Imperativa e Funcional (PIF)** da **CESAR School**, no semestre 2026.2.

O foco principal do curso é o aprendizado da **Linguagem C**, cobrindo desde conceitos fundamentais até tópicos avançados de programação funcional e imperativa, com base na literatura *"Treinamento em Linguagem C"* (Victorine Viviane Mizrahi).

---

## 📁 Estrutura do Repositório

O repositório é organizado em pastas por capítulo/lista de exercícios. Cada pasta contém os arquivos de código-fonte (`.c`) e o documento de respostas teóricas (`respostas.md`):

├── Lista-Cap1/
│   ├── respostas.md
│   ├── exercicio01.c
│   ├── exercicio02.c
│   └── exercicio03.c
├── Lista-Cap2/
│   └── ...
└── README.md


🛠️ Ambiente e Ferramentas
Linguagem: C

Compilador: MinGW (GCC)

IDE / Editor: Visual Studio Code

Controle de Versão: Git & GitHub

📜 Boas Práticas e Diretrizes
Sintaxe e Rigor: Código estruturado atentando ao comportamento case-sensitive da linguagem C, término de instruções com ; e escopo correto por {}.

Modularização: Cada questão prática possui seu próprio arquivo .c individualizado.

Ética e Governança: Uso de ferramentas e IAs de acordo com as diretrizes de governança da CESAR School, priorizando a autoavaliação e o aprendizado ativo.
